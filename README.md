# GreenieRE Vensurety design preview

Static, responsive implementation of the desktop and mobile Figma designs. Hosted on GitHub Pages as a separate test site; the Webflow production site is unchanged.

Open index.html through a static HTTP server. No build dependencies. Fonts and imagery are included locally. Navigation, bond tabs, accordions, and the steps carousel are interactive. Missing application/resource destinations and unsupplied text are identified as preview content. Newsletter validation runs locally and never sends data.
